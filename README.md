# Login Sentinel

> Work in progress.

A Python API that stores login attempts, detects brute-force attacks with SQL and writes incident reports with AI.

## Planned features

- [ ] Generate sample login logs (Python, OOP)
- [ ] Detect brute-force attempts (SQL, SQLite)
- [ ] REST API (FastAPI)
- [ ] AI incident report (Gemini API)

## Resumo em português

API em Python que guarda tentativas de login, detecta ataques de força bruta com SQL e gera relatórios de incidente com IA. Projeto em desenvolvimento.
